# Welcome to OwnCMD

Understand the workspace, choose an edition, and find your first useful workflow.

Applies to: Both

## From a question to a finished task

OwnCMD combines conversational AI with a working environment for research, browser interaction, files, code and scheduled tasks. Chat is the conversational path. Work adds an agent workspace with browser and coding tools. Available models and tools depend on the instance configuration.


## Choose your edition

Cloud is the managed service. New users receive $10 in signup credit; model and tool use consumes credits. Community is the open-source self-hosted edition: install it on your own server, configure your own provider keys, and pay providers and infrastructure vendors directly. Community does not issue or accept OwnCMD credits.


## A practical first task

1. Choose Cloud for managed access, or follow the Community installation guide.
2. Start with a focused Chat request, such as summarizing an uploaded document.
3. Switch to Work for a task that needs the browser, code execution or files.
4. Watch progress, provide requested input, and review the result before taking further action.
5. Open Usage to inspect the activity recorded for the task.

## A first session you can finish in ten minutes

Start with one document or one question rather than a large open-ended assignment. For example, ask: “Read this project brief, identify the three decisions we need to make, and list the evidence missing for each.” Name the intended audience and output format. A clear outcome makes it easier to decide whether the response is useful.

If the next step needs a file or an executable result, move into Work. Ask for a small deliverable first: a CSV comparison, a draft document, or a minimal application. Inspect the result before requesting a larger iteration. The conversation carries your intent; the workspace gives you somewhere to inspect the implementation.


## Understand the main surfaces

- Chat: questions, explanations, document discussion and follow-up reasoning.
- Work: an agent task with access to the configured browser and coding environment.
- Workspace: inspect files, use the editor and terminal, and preview an application when a server is running.
- Skills: reusable instructions and supporting material for recurring types of work.
- Schedules: instructions to run once or repeatedly, with their own execution history.
- Usage: activity records and costs; Cloud shows wallet charges while Community records provider consumption.

## What a successful result looks like

A completed assistant response is not the only thing to review. For research, open the relevant sources and check whether they support the conclusion. For files, download and open the output. For an application, exercise the main interaction in its preview and inspect errors in the terminal. For a scheduled task, inspect its first execution before relying on later runs.

Search this documentation using a feature name or the wording of an error. Use the Cloud or Community filter to avoid following an account or billing flow from the other edition. The on-page contents lets you jump directly to a procedure without reading the whole article.
