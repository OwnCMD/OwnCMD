# Memory and Personal details

Manage reusable preferences and editable form-prefill information.

Applies to: Both

## Save a memory

Open Memory, enter a preference or useful detail, and choose Save memory. The UI allows up to 2,000 characters per entry. Use Forget and confirm to remove a saved memory. Memories personalize future conversations; temporary Chat does not load them.


## Personal details sections

Personal details organizes Contact, Addresses, Preferences, and Additional details. Contact includes fields such as full name, preferred name, email, phone, company, and job title. Use structured fields for information that should prefill Work questions.


## Control prefill

Enable Prefill my Work answers to suggest saved details in relevant Work input requests. Suggestions remain editable and require review before continuing. Save changes explicitly; the interface warns about unsaved changes when leaving.


## Retention and approved inputs

The profile UI describes stored details as encrypted at rest. Turning prefill off does not change inputs already approved for a schedule. Review those schedules separately when removing or changing sensitive details.


## Choose memory or a structured personal field

Use Memory for reusable context such as a preferred writing style or an ongoing project preference. Use Personal details for structured information that should help fill a Work question, such as a contact name or address. They serve related but different purposes; saving an address as prose does not make it the same as a labelled profile field.

A useful memory is short, current, and specific: “Prefer concise explanations with a worked example” is clearer than a long transcript. Avoid storing transient facts that will quickly become wrong. The Memory screen exposes the saved entries so you can remove outdated context with Forget rather than repeatedly correcting it in every conversation.


## Update a profile and review its use

Open Personal details and choose Contact, Addresses, Preferences, or Additional details. Edit the relevant fields and save explicitly. The UI tracks unsaved changes and warns when leaving. Toggle Prefill my Work answers according to whether you want suggestions in Work input requests.

When a question is prefilled, read the values in that request rather than assuming they are correct for every task. A home address, business address, or preferred contact method can be context-dependent. You can change the suggested answer before selecting Continue. The saved profile is a source of suggestions, not a blanket authorization to send all its values to every website.


## Remove stale context thoroughly

Use Forget for an unwanted memory and review Personal details separately for structured values. Turning prefill off prevents that convenience from being used going forward, but it does not rewrite inputs you already approved for a schedule. Open those schedules and update their stored values when a contact detail changes.

Temporary Chat does not load saved memories, although anything you type into its current messages remains part of that temporary context. Encryption at rest protects the stored profile representation; it does not mean a value used for a requested task is never transmitted to the relevant provider or website. Keep credentials and one-time codes out of long-lived reusable context.
