# Changelog

## 1.0.0 — 2026-10-14

- Self-hosted Community edition with closed registration, one-time Owner setup and manual member invitations.
- Optional OpenRouter and Exa keys during installation; encrypted, write-only credentials editable in Instance settings.
- Provider usage tracking without Cloud credits, checkout, SMTP or email verification.
- Chat, Work, browser, code editor, terminal, app preview, documents, skills, memory and schedules.
- Automatic package setup for Ubuntu 24.04/26.04 and Debian 13; capability-based prepared-host path for other systemd distributions.
- Optional domain and HTTPS for trusted private deployments; sandbox security gates remain mandatory.
- Readable installer and source, detailed offline handbook, contribution templates and CI.
- Apache License 2.0 with completed attribution and preserved third-party and earlier MIT notices.

The 1.0 label identifies this distribution; it is not a claim of completed production or per-distribution certification. See [validation](docs/VALIDATION.md) for actual test coverage and outstanding live-host checks.
